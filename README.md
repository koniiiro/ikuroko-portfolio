# ikuroko-portfolio（ポートフォリオサイト）

自身のキャリア（プロフェッショナル翻訳・通訳、バックオフィス事務）と、新たに習得したIT開発スキルを融合させ、多角的な視点から情報発信を行うために構築したオリジナルのポートフォリオサイトです。

「フリーランス翻訳者 / Webデザイナー / フロントエンド学習者」としての歩みを可視化し、自身のスキルセットとこれまでの実績を体系的に紹介しています。

## プロジェクトの目的と学び

* **多才なスキルセットの統合と可視化**
  語学力（TOEIC 900点）、15年の事務遂行力、そしてWeb開発・デザインという異なる領域のスキルが、どのように「一つのプロフェッショナルなリソース」として機能するかを論理的に構成しました。
* **セマンティックなマークアップの実践**
  HTML5/CSS3を用いたモダンなコーディングを行い、レスポンシブデザイン（PC・モバイル対応）による一貫したユーザー体験の提供を目指しました。

## 使用技術 / 開発環境

* **フロントエンド:** HTML5 / CSS3 / JavaScript / Bootstrap 等
* **バックエンド（学習中）:** PHP / Laravel
* **デザインツール:** Figma / Adobe Photoshop
* **バージョン管理:** GitHub

## 主な掲載内容

* **Introduction:** 自身のバックグラウンドと、提供可能な価値の要約
* **Skills:** 語学（英語・日本語）、IT（開発・インフラ基礎）、事務（実務経験）の3軸によるスキルマップ
* **Works（制作実績）:** 
  - Webサイト制作（コーディング・構築）
  - Webデザイン（UI/UX設計）
  - LP（ランディングページ）制作
  - バナー広告・グラフィック制作
  - 翻訳支援および関連ツールの紹介

## こだわった点・工夫したこと

* **洗練された情報設計とタイポグラフィ**
  翻訳者・デザイナーとしての誠実さが伝わるよう、余白とフォント選びにこだわり、情報密度が高くても読みやすい「大人のプロフェッショナル」なトーン＆マナーを意識しました。
* **「実務経験 × IT」のブリッジ表現**
  単なるスキルの羅列ではなく、医療・警察等の電話通訳で培った「現場調整力」や、バックオフィスでの「事務遂行力」が、いかにエンジニアとしての「自走力」に繋がっているかを視覚的に表現しました。
